# 내 차 루틴

삼성 모드 및 루틴의 알림과 공식 차량 위젯을 연결하는 안드로이드 도우미입니다. 개발자: **Im_hwan**.

**ccNC 이전 세대 차량의 루틴 활용을 돕기 위해 만들었습니다.** 모든 차량·휴대폰·앱 버전의 호환성을 보장하지 않습니다. 기아·현대자동차·삼성의 공식 앱이 아닙니다.

## 설치

[Releases에서 APK 다운로드](https://github.com/dlatnqls0815-spec/my-car-routine/releases)

1. 최신 Release의 `MyCarRoutine-0.5.17.apk`를 다운로드해 설치합니다. 처음 설치할 때 Android에서 해당 다운로드 앱의 설치 허용을 요청할 수 있습니다. 설치가 끝나면 불필요한 설치 허용은 꺼 주세요.
2. 내 차 루틴을 열고 **위젯 선택 및 연결**에서 본인의 공식 차량 위젯을 연결합니다.
3. **알림 접근 설정**과 **결과 알림 설정**을 확인합니다. 알림 접근 범위는 [개인정보 안내](PRIVACY.md)를 읽고 직접 허용하세요.
4. **차량과 자동화 설정 → 차량 기능 확인**에서 내 차량과 사용할 기능을 확인합니다.
5. **삼성 루틴에서 사용**을 켜고 사용할 기능에 동의합니다. 새 설치는 실제 요청 기능이 꺼져 있습니다.
6. [사용 설명서](GUIDE.md)에 따라 삼성 루틴을 만듭니다.

같은 개발 서명으로 설치한 이전 Helper는 일반적으로 앱 삭제 없이 업데이트할 수 있습니다. 서명이 다른 앱에는 덮어 설치할 수 없습니다. 이 APK는 개발 서명으로 만든 시험 배포본이며 Google Play 출시본이 아닙니다.

## 가장 먼저 읽어 주세요

> **차문 자동 잠금 사용 시, 시동을 끈 뒤 차량에 차 키와 휴대폰을 두고 내리지 마세요. 키와 휴대폰을 소지했는지 확인한 후 하차하세요.**

- 본인에게 원격제어 권한이 있는 차량만 연결하세요. 연결 차량을 바꾸면 기능을 다시 확인하세요.
- 같은 명령어를 쓰는 다른 삼성 루틴도 차량 요청을 만들 수 있습니다.
- 잠금·잠금 해제·시동은 공통 30초 대기 시간을 공유합니다. 자동 재시도하지 않습니다.
- 앱의 요청 실행 알림은 차량 작동 성공을 보장하지 않습니다. 차량 상태는 차량 또는 공식 앱에서 확인하세요.
- Kia 완료 알림은 화면이 꺼진 상태에서 늦게 나타날 수 있습니다. 알림이 늦다는 이유로 명령을 반복하지 마세요.
- 원격 시동 전 차량 주변과 환기 등 안전 조건을 확인하세요. 공식 앱의 정상 인증 화면이 나타날 수 있습니다.

## 지원 범위

Android 8.0 이상, 삼성 모드 및 루틴, 정상 로그인·차량 등록이 완료된 공식 Kia 또는 마이현대 앱과 차량 위젯이 필요합니다. 차량 서비스 이용 조건은 각 제공자에게 확인하세요.

Kia 1.7.2/1.7.3 및 Samsung SM-F971N·2022 K8 조합에서 사용자가 이전 버전의 잠금·잠금 해제·시동 동작을 확인했습니다. 이것이 모든 차량 또는 이번 배포본 전체를 실차 검증했다는 의미는 아닙니다. **마이현대 위젯 연결은 시험 지원이며 현대차 실차 동작은 미검증입니다.**

주차 위치 알림은 **실험용**입니다. 차량 블루투스가 끊긴 곳의 휴대폰 위치를 주차 위치로 추정하며 차량 GPS를 읽지 않습니다. 이탈·접근 거리와 알림을 각각 선택할 수 있지만 GPS 오차·절전·지하주차장 때문에 늦거나 누락될 수 있습니다. 위치 알림은 차량을 제어하지 않습니다.
